FastAPI App¶

FastAPI app principal avec Gradio monté dessus.

Cette approche permet d’avoir à la fois: 1. Des endpoints REST FastAPI standard (accessibles via curl) 2. L’interface Gradio montée sur un chemin spécifique

Architecture: - GET /api/health -> Endpoint FastAPI direct - GET /api/predict -> Endpoint FastAPI direct - GET / -> Interface Gradio

async src.ui.fastapi_app.api_health()[source]¶

Vérifie la santé de l’API backend.

Returns:

État de santé de l’API

Return type:

JSONResponse

Example

`bash curl https://YOUR-SPACE.hf.space/api/health `

async src.ui.fastapi_app.api_predict(patient_data)[source]¶

Effectue une prédiction de cancer du poumon.

Parameters:

patient_data (dict) – Dictionnaire avec les 14 features du patient

Example

```bash curl -X POST https://YOUR-SPACE.hf.space/api/predict

-H “Content-Type: application/json” -d ‘{

“AGE”: 50, “GENDER”: 1, “SMOKING”: 1, “ALCOHOL CONSUMING”: 0, “PEER_PRESSURE”: 0, “YELLOW_FINGERS”: 1, “ANXIETY”: 0, “FATIGUE”: 1, “ALLERGY”: 0, “WHEEZING”: 1, “COUGHING”: 1, “SHORTNESS OF BREATH”: 1, “SWALLOWING DIFFICULTY”: 0, “CHEST PAIN”: 1, “CHRONIC DISEASE”: 0

}’

```
